        ¿Cómo emparejo el ELM327 Bluetooth en Windows?
        
    
          
  1. Conecta el ELM327 al puerto OBD del Clio (debajo del volante, lado izquierdo) y pon el contacto en ON.
    2. 
          
  2. Windows → Configuración → Bluetooth y dispositivos → Agregar dispositivo → Bluetooth.
    3. 
          
  3. Elige OBDII (o "OBD", "V-LINK"). Si pide PIN, usa 1234 o 0000.
    4. 
          
  4. Windows crea un puerto COM. Aquí elige "Conexión serie estándar por vínculo Bluetooth (COMx)". Si hay dos, prueba con el de número menor.
